# 사용 흐름

헤드셋을 쓰는 순간부터 벗을 때까지. HANDOFF §4 에서 옮긴 초안이에요. 제스처 이름은 공통의 "핸드 인터랙션 패턴"을 따르고, 새 패턴은 거기에 덧붙였어요.

| 단계 | 장소 | 사용자의 목표 | 시스템이 하는 일 | 어떻게 알게 되나 | 실패하면 |
| --- | --- | --- | --- | --- | --- |
| 착용·빠른 시작 | 어디서나 | 바로 쓰기 | 지난 상태(오늘 모은 물감)를 불러와 바로 채집 모드. **물감 0개면 기본 물감 몇 개가 포탈에 들어 있고 "내 방에서 담아 보기" 안내** (바로 푝도, 방 안 채집도 고를 수 있게) | 시작 화면 없이 바로 패스스루 + 손 | 손 인식 전: 손 모양 힌트만 |
| 응시 (Gaze) | 전철 | 창밖 빛을 바라보기 | 머리 레이 중심에 옅은 원. 오래 볼수록 물감이 진해짐 (3초 옅게, 20초 깊게) | 원이 점점 차오르는 게 보임 | 흔들림: 원이 부드럽게 따라옴 |
| 담기 (Catch) | 전철 | 그 빛·재질을 가져가기 | 미리 켜 둔 모드대로: **찰칵**(옷감·벽 같은 정지 재질 → 무늬 보존 2톤 타일) / **루프 온**(물결·잎 → 루프). 무릎 위 한 손 엄지-검지 간격 = 원 크기, 붙이면 담기 → 2톤 + 빛 방향 | 손가락 사이에 물감 방울이 생김 | 너무 어두움: 그래도 담고 표시만 |
| 팔레트 포탈 | 전철·집 | 모은 물감 보기 | 왼손바닥을 위로 뒤집으면 손바닥 위 5~10cm 에 포탈 | 처음 한 번 손바닥 힌트 | 시스템 메뉴: 포탈 중 핀치 금지 |
| 다듬기 | 집 | 범위·루프·톤 고치기 | 레이캐스트, 두 손 프레임 등 큰 동작 허용 | — | **MVP에서 뺌** (11-03 결정, 시간 남으면 폴리시) |
| 푝 (Dab) | 집 | 오브제에 바르기 | 포탈에 손가락 넣었다 빼면 손끝에 물감 → 오브제를 찌르면 닿은 지점부터 번짐. 톡=얇게, 꾹=두껍게. 채집한 빛 방향 = 그림자 방향 | 손끝에 물감이 묻어 있음 | 안 닿음: 손끝 가까이서 호버 반응 |
| 내보내기 | 집 | 게임 에셋으로 쓰기 | GLB + 스프라이트 시트 + JSON | — | — |
| 끝내기·재개 | 어디서나 | 언제든 멈추기 | 자동 저장, 다시 쓰면 그 자리 | — | 중간에 벗음: 담던 물감은 버리지 않고 저장 |

## 대회 테스트와의 대응

- **비행기 좌석:** 전철 단계는 전부 무릎 위 한 손 + 머리 방향
- **버스 한 정거장:** 빠른 시작 + 자동 저장. 10분 안의 순간 = 첫 "푝"
- **첫 5분:** 착용 → 응시 → 담기 → 포탈 → 푝 을 설명 없이 (온보딩은 폴리시 단계)

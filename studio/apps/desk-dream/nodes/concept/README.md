# 콘셉트 · 기준안 깨기

일부러 가장 뻔하게 짠 **측정용 기준안**이에요. 여기서 누구나 예상하는 지점을 찾아, 그중 2~3개를 깨요.

## 기준안 (가장 예상 가능한 흐름)

1. 헤드셋을 쓰면 패스스루로 내 책상이 그대로 보임
2. 책상 위에 반짝이는 파티클이 퍼지며 변신이 시작됨
3. 책상 위에 미니어처 숲·정원·작은 폭포가 자라남
4. 벽이 사라지고 별하늘, 오로라, 떠다니는 섬이 나타남
5. 반딧불과 잔잔한 앰비언트 음악
6. 손을 대면 꽃이 피는 식으로 반응함
7. 페이드아웃 후 원래 책상으로 복귀

## 지도

| # | 관습 | 하는 일 | 예측 |
| --- | --- | --- | --- |
| 1 | 현실에서 시작 | "내 책상"이라는 믿음 만들기 | 중 |
| 2 | 반짝이 파티클 = 마법 시작 | 변화의 신호 | 상 |
| 3 | 자연이 자라남 | 아름다움, 생명감 | 상 |
| 4 | 벽 소멸 + 우주/하늘 | 스케일 확장, 경외감 | 상 |
| 5 | 앰비언트 음악 | 정서 톤 잡기 | 상 |
| 6 | 만지면 핌 | 내가 참여한다는 감각 | 중 |
| 7 | 페이드 후 원상복구 | 마무리, 안전한 귀환 | 상 |

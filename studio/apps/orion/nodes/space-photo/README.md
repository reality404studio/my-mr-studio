# 실제 공간 사진

체험이 일어날 현실 공간(책상, 벽 등)을 사용자 눈높이에서 찍어요. 첫 장면의 시점과 비율 기준이 돼요.

- 꼭 필요: 앉은(또는 선) 눈높이에서 정면 1장
- 있으면 좋음: 위에서 1장, 대각선 1장
- 물건은 치우지 말고 평소대로. 패스스루에서 사용자가 보게 될 "현실"이 바로 이 모습이에요
- 파일 메모에 "정면 / 위 / 대각선"과 실제 크기(cm)를 적어요

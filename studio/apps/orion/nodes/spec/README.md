# 명세 번역

`참조 영상` 을 분해해 이 앱의 `scene_spec.yaml` 로 옮겨요. 구현은 이 파일만 계약으로 봐요.
형식은 공통의 "장면 명세 형식", 성능 태그는 "72fps 성능 규칙", 제스처 이름은 "핸드 인터랙션 패턴"을 따라요.

## 절차 (에이전트)

1. 영상을 1초 간격(변화가 빠른 구간은 더 촘촘히)으로 프레임을 뽑아 본다
2. `objects`: 위치, 크기, 등장 시점과 방식, 반복 애니메이션
3. `timeline`: 시간축 이벤트 (초, 가능하면 박)
4. `interactions`: 손 제스처 → 반응 → 효과음
5. `perf`: 오브젝트마다 태그와 대체안
- `unknowns`: 원본만으로 정할 수 없는 것. 사람이 답해야 하니 끝나면 상태를 `review` 로

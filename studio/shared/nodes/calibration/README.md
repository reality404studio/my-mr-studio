# 책상 캘리브레이션 모듈

책상 위에서 손으로 만지는 모든 앱이 쓰는 모듈이에요. 앱 캔버스에는 "공통" 노드로 연결돼요.
영상이나 스토리보드와 상관없이 먼저 만들어 **실기에서** 검증해요. 손끝과 책상의 교점이 어긋나면 나머지가 다 어긋나요.
Unity 버전 결정 후 시작. 첫 검증 책상: IKEA MICKE 105×50cm, 높이 75cm.

결과물 위치: `unity/shared/DeskCalibration/` (앱들이 패키지처럼 가져다 씀)

## 흐름

1. **1차 추정**: 책상을 바라보면 MRUK Raycast로 책상면을 잡아 반투명 그리드 표시 (방 스캔 불필요)
2. **세 점 찍기**: 왼쪽 앞 모서리, 오른쪽 앞 모서리, 뒤쪽 아무 점에 검지 끝을 대고 0.6초 정지.
   핀치 확인은 손가락이 움직여 오차가 생기니 정지(드웰)로 확정. 정지 동안 여러 프레임 평균
3. **좌표계 생성**: 세 점으로 평면, 앞 모서리 방향(x축), 원점
4. **높이 미세조정**: 1mm 단위 위·아래 버튼. 손끝이 닿을 때마다 물결 효과가 나서
   실제로 닿는 순간과 맞는지 눈으로 확인
5. **저장과 재확인**: 공간 앵커로 저장. 다음 실행 때는 불러온 뒤 4번 탭 테스트만 다시

## 튜닝 파라미터 (초기값은 추정, 실측으로 조정)

| 파라미터 | 의미 | 초기값 |
| --- | --- | --- |
| `fingertip_pad_offset_mm` | 핸드트래킹 손끝 점과 실제 닿는 손가락 바닥면의 차이 | 6 |
| `touch_enter_mm` | 표면까지 이 거리 이내면 "닿음" | 5 |
| `touch_exit_mm` | 이 거리 이상 떨어져야 "뗌" (떨림 방지) | 12 |

## 완료 기준

- [ ] 책상 네 귀퉁이와 가운데를 탭했을 때, 물결이 손끝 아래에서 바로 시작됨 (눈으로 어긋남이 안 보임)
- [ ] 앱을 껐다 켜도 앵커로 위치가 복원됨
- [ ] 72fps 유지

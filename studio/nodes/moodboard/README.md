# 무드보드 · 레퍼런스

모은 에셋을 오른쪽 "파일" 칸에 끌어다 놓고, 파일마다 왜 골랐는지 한 줄씩 적어요.

메모 예시: 전체 분위기 / 이 색감만 / 이 오브젝트 느낌만 / 이 빛만 / 이 움직임만

"몽환적인 핑크 구름" 같은 형용사만으로 프롬프트를 쓰면 영상 모델은 그 단어의 평균을 그려요.
그래서 무드보드에서 색, 빛, 질감, 움직임을 구체적인 어휘로 뽑아 프롬프트에 써요.

## 에이전트가 할 일

- [ ] 모든 파일과 메모를 보고 아래 네 가지로 정리해 이 문서에 덧붙이기
  - 색: hex 4~6개와 각 색의 역할 (배경 안개, 강조, 그림자 등)
  - 빛: 광원 방향, 부드러움, 발광 여부
  - 질감: 표면 재질 (솜사탕, 반투명 젤리, 무광 플라스틱 등)
  - 움직임: 속도와 리듬 (천천히 부풀기, 떠다니기 등)
- [ ] 메모가 "이 부분만"인 파일은 그 부분만 반영
- [ ] 정리가 끝나면 상태를 `review` 로

01색 — 세 안 (서로 다른 축)

모두 레퍼런스에서 뽑은 값이에요 (r10 코발트 #2559B4, r9 클라인 #15317C, r9 종이 #F0EEE6, r4 하늘, r7·r10 빨강). 아래 회색 띠는 패스스루 대용. 차이는 "선이 무슨 색이냐"와 "빨강을 언제 쓰냐"예요.

축: 선의 색 = 잉크

A · 클라인 잉크

선 #15317C
면 #2559B4
종이 #F0EEE6
점 #D23A2C

진짜 도면처럼 진한 잉크선. 밝은 하늘·낮 풍경에선 또렷, 밤 전철 창(어두움)에선 묻힘. 외곽선 = 같은 잉크.

축: 선의 색 = 빛

B · 흰 제도선

선 #F0EEE6
표제 #2559B4
보조 #7FA6D9
점 #D23A2C

청사진을 뒤집은 것. 어두운 창밖에서 강함, 흰 벽·하늘에선 약함 → 얇은 남색 그림자 테두리 필요. 코발트는 표제란·타일 라벨 "인쇄물"에만. 외곽선 = 클라인.

축: 색이 상태를 말함

C · 코발트 → 빨강

대기 #7FA6D9
응시 #2559B4
담김 #D23A2C
종이 #F0EEE6

하늘색에서 시작해 오래 볼수록 코발트로 짙어지고, 담는 순간만 빨강. 색 = 응시 진하기라 인과가 바로 보임. 대신 빨강이 "포인트 한 점"이 아니라 상태색이 됨.

공통: 빨강은 화면에 한 번에 한 점만(r7·r10 규칙). 노랑(r10 SPACE 제목)은 넣지 않았어요 — 넣고 싶으면 말해 주세요. 대비 기준은 Meta 4.5:1(글자) / 3:1(선), 패스스루 위에선 실기로만 확인 가능.

04실측 HUD — 찰칵 / 루프 온 초안

색은 A안(클라인 잉크)을 흰 테두리로 받쳐 그렸어요 — 색 안을 고르면 다시 칠해요. 같은 측량 원인데, 루프 온은 원 둘레를 점선 링이 돌며 타임코드가 계속 올라가요.

걸리는 점: 모드 토글 위치. 전철에선 한 손이 무릎 위에서 핀치 중이라 같은 손으로 토글할 수 없어요. 초안은 "왼손목 위, 오른손으로 톡". 대안: 왼손바닥 포탈 가장자리에 붙이기, 또는 두 손가락 핀치(중지) 같은 제스처. 사람이 고를 것.

06움직임 문법 — "도면이 스스로 그려진다" 초안

순간그려지는 순서시간
응시 시작중심 십자 → 숨은선 원이 한 바퀴 그어짐(시계 방향, 12시에서)0.35s
응시 누적숨은선이 실선으로 메워짐 · 축척 막대가 참 · 선이 아주 조금 굵어짐3~20s, 계속
반경 조절치수선이 늘었다 줄어듦, 숫자가 따라 굴러감 (이징 없이 손 그대로)실시간
담기외형선으로 "탁" 굵어짐 → 빨간 점 → 빛 방향 중심선이 뻗음 → 표제란 줄이 위에서 아래로 그어짐0.6s
포탈 열기격자선 → 타일 꽂힘 (가까운 것부터 0.04s 간격)0.4s
푝접촉점에 작은 치수 원 → 재료가 번짐 (셀 셰이더 쪽) → 원이 사라짐0.5~1.2s

예외 상태도 같은 문법: 너무 어두움 = 표제란에 "LOW LIGHT" 스탬프(그래도 담김) · 손 놓침 = 측량 원이 숨은선으로 돌아가 기다림 · 빈 포탈 = 빈 격자 + 기본 재료 3칸 + "내 방에서 담아 보기" 한 줄.

07소리 방향표 — 동화 초안

이벤트소리잔향 · 빈도이유
응시 누적유리 오르골 음이 하나씩 쌓임 (3초마다 한 음, 펜타토닉)길게, 겹쳐도 화음응시 시간이 귀로도 쌓임 = 관측 가능성
담기작은 종 한 번 + 종이에 도장 찍는 듯한 둥근 "톡"짧게동화(종) + 인쇄(도장)를 한 소리에
포탈 열기낡은 상자 뚜껑의 부드러운 바람 소리 (나무 삐걱임 없이)중간생활 소음 금지 규칙 지킴
타일 꺼내기타일마다 음높이가 다른 작은 글로켄슈필짧게재료마다 음 하나 = 재료의 이름표
푝물감 방울 "퐁" + 번지는 동안 아주 옅은 바람번짐 길이만큼"푝" 이라는 이름과 소리를 맞춤

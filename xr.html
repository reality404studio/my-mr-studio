헤드셋 그레이박스

명세의 objects 를 책상 위에 회색 상자로 띄우고, 헤드셋 안에서 바로 메모를 남겨요.

  1. 마이크 허용을 누르고, 브라우저 질문에 허용해요
  2. 헤드셋으로 들어가기 → 검지 끝을 책상 앞 모서리 가운데에 대고 잠깐 멈추면 책상이 맞춰져요
  3. 왼손 손바닥을 얼굴 쪽으로 → 빨간 버튼을 오른손 검지로 찌르고 말해요. 다시 찌르면 저장

헤드셋에서 이 페이지가 안 열리면

WebXR 과 마이크는 보안 연결에서만 돼요. 둘 중 하나로 열어요.

1) USB: 맥에서 adb reverse tcp:5173 tcp:5173 후 헤드셋 브라우저에서 http://localhost:5173/xr.html?app=…

2) 같은 Wi-Fi: 맥에서 npm run dev:xr 후 터미널에 뜬 https://192.168…:5173 주소. 인증서 경고가 뜨면 "고급 → 계속".

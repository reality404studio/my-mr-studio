# 결정 기록: 정한 것 / 안 하기로 한 것

- [`studio/shared/DECIDED.md`](../../DECIDED.md) — 사람이 직접 내린 결정. 원문과 날짜. 다시 묻지 않는다
- [`studio/shared/REJECTED.md`](../../REJECTED.md) — 사람이 거절한 방향. 같은 제안은 여기 적힌 대로 답한다

공통과 앱 결정을 한 파일에 두고 `[공통]` / `[앱 id]` 로 구분해요. 보드의 `decide` 하위 과업을 사람이 `done` 으로 바꾸면,
에이전트가 그 결정을 여기에 옮겨 적어요 (사람이 쓴 말 그대로).

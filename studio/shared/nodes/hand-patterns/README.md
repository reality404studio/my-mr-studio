# 핸드 인터랙션 패턴

컨트롤러 없이 손만 쓰므로, 앱들이 같은 동작에 같은 규칙을 쓰게 여기서 정해요.
앱에서 새 패턴을 만들면 여기에 덧붙여요.

| 패턴 | 언제 | 규칙 (초안) |
| --- | --- | --- |
| 손끝 탭 (책상 면) | 책상 위 물체 누르기 | 닿음 5mm 이내, 뗌 12mm 이상 (떨림 방지) |
| 포크 (공중 버튼) | 패널 버튼 | 버튼 앞면을 손끝이 통과하면 눌림 |
| 핀치 | 집어서 옮기기 | 정확한 위치 확정에는 쓰지 않음 (핀치 순간 손가락이 움직임) |
| 드웰 (멈춤) | 위치 확정 | 0.6초 정지, 그동안 여러 프레임 평균 |
| 손바닥 위로 | 메뉴 열기 | 손바닥이 얼굴을 향하고 0.3초 유지 |
| 호버 | 미리보기, 반응 | 손끝 3cm 이내면 은은한 반응 |
| 헤드셋 메모 | 만들면서 느낌 남기기 (개발용) | 왼손 손바닥 위로 0.3초 → 손바닥 위 6cm 버튼을 오른손 검지로 찌름 (2cm 안 들어오면 눌림, 3.5cm 나가야 다시). 녹음 중엔 손을 돌려도 버튼 유지 |

- [ ] 실기에서 각 수치 검증 (캘리브레이션 모듈과 함께)

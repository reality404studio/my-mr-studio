# 장면 명세 형식

모든 앱은 `scene_spec.yaml` 하나를 구현 계약으로 써요. 새 앱을 만들면 `studio/shared/scene_spec.template.yaml` 이 복사돼요.
영상 우선이든 스토리보드 우선이든, 마지막에는 이 형식으로 모여요.

| 블록 | 담는 내용 |
| --- | --- |
| `meta` | 제목, 원본(영상 또는 스토리보드), 길이, BPM |
| `desk` | 좌표 규칙, 상판 크기, 캘리브레이션 값 (책상 기반 앱) |
| `objects` | 위치, 크기, 등장 방식, 반복 애니메이션 |
| `timeline` | 시간축 이벤트 |
| `interactions` | 손 제스처 → 반응 → 효과음 (핸드 인터랙션 패턴 이름 사용) |
| `perf` | 72fps 규칙에 따른 태그와 대체안 |
| `unknowns` | 원본만으로 정할 수 없는 것. 사람이 답함 |
| `review` | 실기와 원본의 차이 |

형식을 바꾸면 템플릿 파일도 함께 고쳐요. 이미 만든 앱의 명세는 자동으로 바뀌지 않아요.

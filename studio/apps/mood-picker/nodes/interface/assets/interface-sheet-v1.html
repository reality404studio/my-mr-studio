이탤릭·Light 없음. 제목은 큰 크기에서만. 흰 선 위 글자는 항상 남색 받침 테두리.

02실측 HUD — 정사각형 프레임

왼쪽: 양손 핀치로 정사각형을 잡는 중(두 핀치 지점이 대각 모서리). 가운데: 기록 중, 둘레를 따라 진행선이 한 바퀴 그어지면 자동으로 담김. 오른쪽: 담기는 순간 — 즉석 사진처럼 칩이 위로 빠져나옴.

열린 것 — 기록 시간: 자동으로 담기는 시간을 무엇이 정하나요? 예전 결정은 "응시 시간 = 진하기·루프 길이"였어요. 베이스라인 초안은 고정 시간(STILL 3초, LOOP 4초)으로 그렸어요. 다른 안: 정사각형을 잡고 있는 동안 계속 기록하고, 손을 떼면 그때까지가 기록 시간.

LOOP 모드는 같은 프레임에 타임코드가 계속 올라가고, 진행선이 점선 링으로 한 번 더 돌아요. 토글(한 손 핀치)을 하면 왼쪽 위 글자가 STILL ↔ LOOP 로 바뀌고, 프레임이 숨은선으로 한 번 다시 그어져요.

03모은 재료 — 컬러 차트 칩 × 즉석 사진

칩 = 위 정사각 재료, 아래 흰 라벨 띠(즉석 사진의 넓은 아래 테두리). 포탈에서는 손바닥 위에 칩이 부채꼴로 겹쳐 펼쳐져요. 특정 회사의 칩 레이아웃·로고·번호 체계는 따라 하지 않아요.

# 참조 영상 만들기

보고 싶은 화면을 컷 단위 영상으로 고정해요. 하위 과업 순서대로 진행해요.

## 컷 프롬프트에 적을 것

- **시점**: 사용자 1인칭 눈높이, 카메라 거의 고정. 드론샷, 빠른 이동, 급한 회전 금지 (VR 멀미)
- **현실**: 실제 공간 사진을 참조 이미지로, 실제 크기감 유지
- **변화**: 이 컷에서 일어나는 일 한 가지 (무엇이, 어디서, 어떻게)
- **색·빛·질감·움직임**: 무드보드 어휘표의 단어 그대로
- **소리**: BGM 분위기, 상호작용 효과음
- **성능**: 공통 "72fps 성능 규칙"에서 impossible 인 표현은 넣지 않기

## 프롬프트

_컷 구성이 끝나면 작성_

## 파일

생성한 컷은 이 과업의 파일 칸에 올리고 메모에 컷 번호와 "사용 / 버림: 이유"를 적어요. 최종본은 `final.mp4`.

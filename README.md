# VR 앱 만들기

Quest 3S 패스스루 앱들을 만드는 공통 작업대예요. 칸반처럼 **단계(열) > 과업(카드) > 하위 과업(행)** 으로 정렬된 보드에서,
사람과 에이전트가 같은 파일을 보고 고쳐요. 보드의 1순위 독자는 에이전트예요.

```
VR 앱 만들기
├─ 공통      모든 앱이 함께 쓰는 조건, 결정, 모듈 (플랫폼 조건, Unity 버전, 72fps 규칙, 핸드 패턴, 책상 캘리브레이션 …)
└─ 앱들      앱마다 보드 하나. 만들 때 모드를 고름
   ├─ 책상 위 꿈        영상 우선
   └─ (새 앱)           스토리보드 우선 …
```

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 열면 홈이 나와요.

## 보드 구조

```
단계         정의 → 레퍼런스 → 영상 → 명세 → 구현 → 검수        (열, 왼쪽에서 오른쪽)
과업         무드보드: 시각 언어                                  (산출물 하나를 책임지는 묶음)
하위 과업      수집 · 에셋 올리고 이유 메모 달기        사람
               분석 · 색·빛·질감·움직임 어휘표          에이전트
               결정 · 어휘표 확인                       사람
```

- 하위 과업마다 **특성**(결정, 수집, 분석, 작성, 생성, 구현, 검증)과 **하는 쪽**(사람, 에이전트)이 있어요
- 과업의 상태는 하위 과업에서 계산되고, 연결된 앞 과업이 끝나야 다음 과업이 시작돼요
- "지금 할 일"은 지금 시작할 수 있는 하위 과업만 보여줘요. 에이전트는 `npm run studio -- next` 로 같은 목록을 봐요

## 모드

| 모드 | 출발점 | 단계 |
| --- | --- | --- |
| 영상 우선 | 보고 싶은 화면 | 정의 → 레퍼런스 → 영상 → 명세 → 구현 → 검수 |
| 스토리보드 우선 | 사용 흐름 | 정의 → 설계 → 프로토타입 → 명세 → 구현 → 검수 |

모드는 `studio/templates/` 의 폴더예요. 폴더 하나를 복사해 고치면 새 모드가 생겨요.

## 할 수 있는 것

- **홈**: 공통 띠와 앱 카드. 카드의 띠 한 칸이 과업 하나, 색이 상태. 앱마다 지금 할 일 하나
- **새 앱 만들기**: 이름, id, 모드를 고르면 단계와 과업이 깔린 보드가 생겨요
- **과업과 하위 과업**: 열 머리의 "과업 추가", 과업을 열면 하위 과업 추가와 순서 바꾸기(↑↓)
- **단계 편집**: 열 머리에 마우스를 올리면 이름 바꾸기, 좌우 이동, 빈 단계 지우기. 맨 오른쪽 "단계 추가"
- **연결**: 과업 카드 오른쪽 점을 끌어 다른 과업 왼쪽 점에. 연결을 누르면 지울 수 있어요
- **공통 과업 가져오기**: 앱 보드에서 "공통" 과업을 추가하고 가져올 과업을 골라요. 상태는 공통을 따라가요
- **상세 편집**: 카드나 하위 과업 행을 누르면 상태, 특성, 하는 쪽, 방법, 메모(마크다운 자동 저장), 파일
- **무드보드**: 파일 칸에 이미지를 끌어다 놓고 이미지마다 "왜 골랐는지" 메모
- **실시간 반영과 기록**: 에이전트가 파일을 고치면 바로 보이고, 누가 무엇을 했는지 남아요

## 에이전트와 함께 쓰기

규칙은 [AGENTS.md](AGENTS.md), Claude Code는 [CLAUDE.md](CLAUDE.md) 를 자동으로 읽어요.

```bash
npm run studio -- apps
npm run studio -- next --app desk-dream --by agent
npm run studio -- list --app desk-dream
npm run studio -- show moodboard-analyze --app desk-dream
npm run studio -- status moodboard-analyze doing --app desk-dream --as "Claude Code"
npm run studio -- new-app hand-garden "손끝 정원" --mode storyboard-first --as "Claude Code"
```

다른 컴퓨터나 클라우드 에이전트와는 평소처럼 커밋하고 푸시해서 공유해요.

## 구조

```
src/        웹 화면 (React + React Flow)
server/     파일 저장소와 API (Vite 개발 서버에 붙음)
scripts/    에이전트용 CLI
studio/     공통, 앱, 모드  ← 진실의 원천
unity/      Unity 프로젝트 (앱별, 공용 모듈)
```

## 첫 버전에서 올라온 경우

예전에는 `studio/` 바로 아래에 한 앱만 있었어요. 또 노드를 자유롭게 배치하던 보드는 처음 읽을 때 위치의 열을 단계로 바꿔 정렬해요. 서버나 CLI를 처음 실행할 때 예전 위치에 남은 파일
(커밋하지 않은 무드보드 등)은 `studio/apps/desk-dream/` 과 `studio/shared/` 로 자동으로 옮겨져요.

# 먹의 농담

손이 종이 위를 지난 거리와 접촉한 시간을 따로 적분하는 수묵 입자 엔진. 폭 12cm의 가상 붓으로 같은 62cm를 빠르게 긋거나 느리게 긋거나 가운데서 멈춰 비교한다. 브라우저의 직접 그리기는 마우스, 터치, 펜을 받는다.

저장소 루트에서 `python3 -m http.server 8000 --directory public`을 실행한 뒤 `http://localhost:8000/ink-study/`를 연다. 서버에서 외부 파일을 내려받을 필요는 없다. 검증은 `node --test test/*.mjs`로 실행한다.

| 파일 | 역할 |
| --- | --- |
| [ink-engine.js](./ink-engine.js) | 붓 다발, 입자 방출, 종이 안의 이동과 고착, 농담 렌더링, 기존 스플랫 배치 연결 |
| [replay.js](./replay.js) | 속도와 정지 시간만 바꿔 같은 궤적을 재생 |
| [study.js](./study.js) | 비교 시료와 직접 그리기. 동일한 엔진을 두 입력 경로에서 사용 |

## 붓에서 종이까지

1. 손끝을 고정한 평면에 투영한 좌표(m)와 시각(s), 접촉도(0–1)를 입력한다. 접촉을 시작할 때 `begin`, 추적 중 `sample`, 손을 떼거나 추적을 잃으면 `lift`를 보낸다. 같은 위치에서도 최신 관절 추적이 유효한 동안 매 프레임 시각을 갱신한다.
2. 붓을 120Hz로 샘플링한다. 29개 다발의 횡방향 오프셋과 길이 편차가 획을 따라 지속된다. 다발은 움직인 거리와 접촉한 시간에 따라 물과 안료를 담은 타원형 입자를 내린다. 체류 시 공급의 일부를 넓은 원형 자국에 배분한다.
3. 입자가 닿으면 종이결의 거칠기에 따라 분배하되 영역 안의 가중치 합으로 정규화해 먹의 양을 보존한다. 30Hz로 젖은 영역에서 물이 두 축의 투과율에 따라 이웃으로 이동한다. 일부 안료는 물에 실리고 나머지는 고착된다. 시료마다 종이결의 시드를 고정하므로 차이는 손과 붓 조건에서 온다.
4. 색은 바탕 종이와 먹의 하한 밝기를 면적당 안료량의 지수 감쇠로 섞는다. 비교 시료는 손을 뗀 뒤 각각 0.8초 지난 모습이다. 물기, 먹 농도, 처음 묻힌 양을 따로 바꿀 수 있다.

## WebXR 연결 범위

기존 [먹 입자 배치](../ink-crow/ink.js)의 `SplatBatch.put` 형식을 사용한다. `writeInkSplats(paper, batch, origin, right, down, now)`는 종이의 안료 중심을 월드 공간으로 옮기고 배치 한도에 맞춰 묶는다. 촘촘한 붓결 검수는 실험판의 2D 해상도를 기준으로 한다. WebXR에서는 세계에 고정한 획 평면에 손 관절을 투영하고, 양 눈에 공유할 배치를 한 번 갱신하는 것이 다음 연결점이다. 브러시 구현과 기기에서의 추적 안정성·성능은 별도로 검증한다.

물과 안료를 분리하고 섬유에 고착시키는 모델의 선행 연구는 [Curtis 외, Computer-Generated Watercolor (1997)](https://grail.cs.washington.edu/projects/watercolor/)를 참고했다.

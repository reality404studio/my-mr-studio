# 명세 번역

`사용성 스토리보드` 을 분해해 이 앱의 `scene_spec.yaml` 로 옮겨요. 구현은 이 파일만 계약으로 봐요.
형식은 공통의 "장면 명세 형식", 성능 태그는 "72fps 성능 규칙", 제스처 이름은 "핸드 인터랙션 패턴"을 따라요.

## 절차 (에이전트)

1. 스토리보드 표의 컷마다 `timeline` 이벤트와 `interactions` 항목을 만든다
2. 그레이박스에서 확정한 치수로 `objects` 의 위치와 크기를 채운다
3. 사용성 테스트에서 바뀐 점을 반영했는지 확인한다
4. `perf`: 오브젝트마다 태그와 대체안
- `unknowns`: 원본만으로 정할 수 없는 것. `unknown spec "질문" --field <칸>` 으로 남기면 사람 화면의 결정 대기에 떠요. 추정한 값은 `assume ... --confidence low` 로. 끝나면 상태를 `review` 로

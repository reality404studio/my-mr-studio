## 이 앱에서만 지키는 규칙

- **핸즈 퍼스트:** 컨트롤러를 한 번도 연결하지 않고 끝까지 완주돼야 한다 (하드 요구사항)
- **비행기 좌석:** 모든 인터랙션이 앉은 자세 반경 약 60cm 안. 전철에서는 팔을 뻗지 않는다
- **가져가 보기:** 외부 서비스를 빼도 동작. 클라우드 추론 쓰지 않음
- **프라이버시:** 손으로 지정한 작은 영역만 크롭, 원본 프레임 저장 금지. 데모 영상에 타인 얼굴 금지
- **MVP 선:** 머리 레이 + 핀치 채집 → 정지 텍스처 + 2톤 + 빛 방향 → 왼손 포탈 → 페트병 하나에 "푝" → 셀 셰이더. 루프는 그 다음
- **창작 결정은 사람이:** 디자인·연출 선택지는 서로 다른 축 2~5개로 내고 멈춘다 (HANDOFF §9)

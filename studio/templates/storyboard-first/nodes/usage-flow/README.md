# 사용 흐름

헤드셋을 쓰는 순간부터 벗을 때까지 사용자가 겪는 흐름을 단계로 적어요. 스토리보드는 이 흐름을 컷으로 쪼갠 것이에요.

| 단계 | 사용자의 목표 | 시스템이 하는 일 | 실패하면 |
| --- | --- | --- | --- |
| 착용 | | | |
| 공간 맞추기 (캘리브레이션) | | | 손 인식이 끊기면? |
| 처음 안내 | | | |
| 핵심 경험 | | | |
| 자유롭게 놀기 | | | |
| 끝내기 | | | |

- 손만 쓰므로 "어떻게 할 줄 알게 되는지"(안내 없이 알아채는지, 보여주는지)를 단계마다 적어요
- 제스처 이름은 공통의 "핸드 인터랙션 패턴"에 있는 것을 써요

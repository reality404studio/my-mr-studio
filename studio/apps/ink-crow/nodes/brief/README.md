# 묵전 · 까마귀 소환

한 자리에 선 소환사가 눈앞에 굵은 먹진을 그리고, 손바닥으로 주입한 기운으로 까마귀를 불러낸다. 상대는 삿갓을 쓴 먹객 한 명이다.

| 손이 하는 일 | 보이는 결과 |
| --- | --- |
| 검지를 펴거나 핀치한 채 한 바퀴 그린다 | 손끝의 실제 궤적에 지름 약 12cm의 먹붓이 지나간다. 물 먹은 가장자리와 갈라진 붓털 사이로 바탕이 비친다. |
| 원의 시작점 근처로 돌아온다 | 짧은 틈을 잇고, 진 가장자리의 먹이 안쪽으로 돌며 모인다. |
| 손바닥을 진 쪽으로 펴고 중앙에 댄다 | 손바닥에서 먹과 주사가 실처럼 뻗는다. 약 1.35초를 채우면 중앙에 烏가 맺힌다. 일찍 손을 떼면 충전량이 줄어든다. |
| 손을 놓고 지켜본다 | 같은 입자들이 새의 몸통과 깃을 이루고 한 번 날갯짓한 뒤 상대에게 급강하한다. 세 번 명중하면 승리한다. |
| 상대가 붉은 진을 그린다 | 조준이 끝나고 붉은 먹이 날아올 때 고개를 옆으로 움직여 피한다. |

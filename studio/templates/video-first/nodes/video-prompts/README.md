# 영상 프롬프트

- 입력: 무드보드 분석, 실제 공간 사진, 콘셉트에서 고른 깰 지점
- 출력: 체험을 컷으로 나눈 프롬프트. 컷마다 코드 블록 하나
- 영상 생성은 사람이 직접 해요 (예: Google 영상 모델). 에이전트는 프롬프트만 써요

## 컷마다 적을 것

- **시점**: 사용자 1인칭 눈높이, 카메라 거의 고정. 드론샷, 빠른 이동, 급한 회전 금지 (VR 멀미)
- **현실**: 실제 공간 사진을 참조 이미지로, 실제 크기감 유지
- **변화**: 이 컷에서 일어나는 일 한 가지 (무엇이, 어디서, 어떻게)
- **색·빛·질감·움직임**: 무드보드 분석의 어휘 그대로
- **소리**: BGM 분위기, 상호작용 효과음
- **성능**: 공통의 "72fps 성능 규칙"에서 `impossible` 인 표현은 영상에도 넣지 않기

## 프롬프트

_무드보드 분석과 콘셉트 선택이 끝나면 작성_

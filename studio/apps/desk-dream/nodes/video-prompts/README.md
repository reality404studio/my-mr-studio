# Google 영상 프롬프트

- 입력: 무드보드 분석, 실제 책상 사진, 콘셉트에서 고른 깰 지점
- 출력: 1분 투어를 6~8컷으로 나눈 프롬프트. 컷마다 코드 블록 하나
- 영상 생성은 사람이 Google 영상 모델에서 직접 해요. 에이전트는 프롬프트만 써요

## 컷 프롬프트 형식

각 컷에 아래 항목을 빠짐없이 적는다.

- **시점**: 앉은 사람의 1인칭 눈높이, 책상을 살짝 내려다보는 각도. 카메라는 거의 고정
  (헤드셋 시점 흉내. 드론샷, 빠른 이동, 급한 회전 금지 — VR에서 멀미가 나는 움직임이에요)
- **현실**: 실제 책상 사진을 참조 이미지로. 책상 크기 105×50cm 감각 유지
- **변화**: 이 컷에서 일어나는 일 한 가지 (무엇이, 어디서, 어떻게)
- **색·빛·질감·움직임**: 무드보드 분석의 어휘를 그대로 사용. 형용사만 쓰지 않기
- **소리**: BGM 분위기, 상호작용 효과음
- **길이**: 모델의 컷 길이 제한에 맞춤

## 주의

- 특정 제품, 브랜드, 캐릭터를 복제하는 표현은 쓰지 않는다. 오리지널 디자인으로 묘사
- 퀘스트에서 비싼 표현(겹겹의 반투명 구름, 강한 실시간 그림자)은 영상에서도 절제한다.
  영상이 예쁘고 구현이 불가능하면 4단계에서 다시 그려야 해요

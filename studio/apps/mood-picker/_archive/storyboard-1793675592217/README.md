# 사용성 스토리보드

> 이 형식은 초안이에요. 쓰고 계신 콘셉트·사용성 스토리보드 양식이 있으면 그 양식으로 바꿔 주세요.
> 에이전트는 이 문서의 표 구조를 그대로 읽어 명세로 옮겨요.

컷 스케치(손그림, 생성 이미지 무엇이든)를 파일 칸에 올리고, 파일 메모에 컷 번호를 적어요.

| 컷 | 장면 (사용자가 보는 것) | 사용자 행동 (손, 시선) | 시스템 반응 (시각, 소리) | 이 컷의 의도 | 테스트에서 볼 것 |
| --- | --- | --- | --- | --- | --- |
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

## 컷을 쓸 때

- 한 컷에 사용자 행동은 하나
- "반짝인다" 대신 무엇이, 어디서, 얼마나 (책상 좌표나 손과의 거리)
- 시선 밖(옆, 뒤)에서 일어나는 일은 소리나 빛으로 알려주는지 적기

# Unity 구현

- 계약은 `studio/scene_spec.yaml` 하나. 영상은 참고만
- 기기: Quest 3S 패스스루, 핸드트래킹만, 72fps 유지
- 캘리브레이션 결과(`desk` 좌표계) 위에 모든 오브젝트를 배치
- Unity 프로젝트는 레포의 `unity/` 폴더에 둔다

## Mac 개발 루프

| 루프 | 도구 | 확인하는 것 |
| --- | --- | --- |
| 빠른 루프 | Meta XR Simulator (Apple Silicon) | 배치, 등장 순서, 타임라인, 사운드 연결 |
| 실기 루프 | USB로 APK 빌드 후 설치 | 손끝 접촉 정확도, 72fps, 패스스루 위 색감 |

Mac은 Link를 쓸 수 없어 실기 확인은 매번 APK 빌드예요. M1 Air는 빌드가 느린 편이라 실기 루프는 하루 몇 번으로 묶어요.

## 성능 원칙

- 반투명 겹침 대신 불투명 메시 + 디더링
- 실시간 조명·그림자 대신 발광 재질 + 가짜 그림자
- 반복되는 것(키캡 등)은 인스턴싱, 물고기는 셰이더 애니메이션

# 72fps 성능 규칙

Quest 3S 독립형에서 72fps를 지키기 위한 기본값이에요. 앱의 명세(`perf` 블록)는 이 규칙으로 태그를 붙여요.

| 표현 | 태그 | 대신 쓰는 것 |
| --- | --- | --- |
| 반투명이 여러 겹 겹치는 구름·안개·연기 | 비쌈 | 불투명 메시 + 디더링, 개수 제한 |
| 실시간 조명과 그림자 | 비쌈 | 발광 재질 + 바닥에 가짜 그림자 텍스처 |
| 같은 물체가 많이 반복 (키캡, 잎) | 가능 | GPU 인스턴싱 |
| 뼈대 애니메이션 생물 여러 마리 | 비쌈 | 셰이더로 흔들기, 소수만 |
| 큰 파티클 수 | 비쌈 | 작은 수 + 큰 크기 + 발광 |
| 후처리 (블룸, 피사계 심도) | 거의 불가 | 재질 자체를 밝게, 그라데이션 텍스처 |
| 텍스트 | 가능 | TextMeshPro |

태그 뜻: `ok` 그대로 / `costly` 대체안과 함께 / `impossible` 영상·스토리보드에서 빼거나 다시 그림

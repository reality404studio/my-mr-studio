# 앱 개요 (Letter Pigment Splat)

이 앱만의 조건을 적어요. 기기, 입력, 성능 같은 공통 조건은 **공통** 캔버스의 "플랫폼 조건"에 있어요.
원천 브리프: `splatter/letter-pigment-splat-brief.md`

## 이 앱에서만 지키는 규칙

- **단일 Unity 폴더(`unity/mood-picker/`) 내 `splatter` 브랜치 사용**: `Library/` 중복 생성을 막기 위해 새 Unity 프로젝트를 파지 않고 `splatter` 브랜치에서 작업한다 (`main` = mood-picker, `orion` = ORION).
- **물감 파이프라인 고정 (브리프 §2)**:
  1. 프레임 수집 (최대 6초, 256px 정사각 크롭, 연속 동일 프레임 차이 0 제외)
  2. 루프 탐색 (Schödl 2000: 64×64 luma 차이 행렬 `D[i,j]`, 크로스페이드 구간 가중 평균 비용 / `base` 중앙값 최소화)
  3. 크로스페이드 (`smoothstep((t+0.5)/F)`) 및 최대 48프레임 솎기 (`cols = ceil(√n)`, `rows = ceil(n/cols)`)
  4. 이음매 없는 타일 = 주기화 (Moisan 2011 FFT: 경계 점프만 저주파로 흡수, **크롭 → 크로스페이드 → 주기화 → 2톤** 순서 엄수)
  5. 아틀라스 규칙: 밉맵 끄기(`mipmapEnabled: false`), Linear(Bilinear) 필터, `Clamp` 랩, 반 텍셀(`0.5 / tile`) 클램프
  6. 2톤 색 추출: k-means (`k=2`, 10회, 초기값 밝기 20%/80%) → `light`, `shadow`, 경계값 `th = (luma(light) + luma(shadow)) / 2` (sRGB 기준)
- **가우시안 스플랫 글자 구조 (브리프 §6)**:
  - 글자 표면(앞·뒷면·옆면·베벨 포함)에서 **면적 비례로 점과 노멀을 샘플링**해 납작한 표면 스플랫(접평면 두 축 = 샘플 간격, 노멀 축 = 1/10 이하, 회전 = 노멀 기준 쿼터니언) 생성
  - 스플랫 위치·노멀은 글자 로컬 공간에 고정하고, 매 프레임 GPU 셰이더에서 스플랫 중심 위치 + 저장된 노멀로 플립북 아틀라스를 트라이플래너 샘플링
  - Chrome 모드의 범프는 화면 미분(`ddx/ddy`) 대신 **텍스처 공간 유한 차분(`h(uv ± ε)`)**으로 스플랫 노멀을 흔든다
  - 2톤 셀 외곽선은 노멀 반대/바깥·뒤쪽으로 살짝 밀어낸 **남색(`#2E3350`) 스플랫 한 겹**으로 표현한다

# Quest 3S 검수

브라우저의 데스크톱 시연과 합성 손 관절 입력으로 검증했다. Quest 3S 착용 시험은 대기 중이다.

- 실제 손으로 양방향 원을 그려 붓 굵기와 원 끝을 닫는 허용 범위를 본다.
- 손바닥을 원 앞, 중앙, 바깥으로 옮겨 주입의 시작·이탈이 예상한 위치에서 일어나는지 본다.
- 패스스루에서 방의 밝기에 따른 먹색과 손 앞으로 떨어지는 깃의 깊이를 본다.
- **? → 헤드셋에서 프레임 간격 표시**를 켜고 소환·명중을 세 번 반복한다. 72Hz의 프레임 예산은 약 13.9ms다.

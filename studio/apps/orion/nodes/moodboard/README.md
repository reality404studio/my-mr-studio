# 무드보드

모은 에셋을 오른쪽 "파일" 칸에 끌어다 놓고, 파일마다 왜 골랐는지 한 줄씩 적어요.
예: 전체 분위기 / 이 색감만 / 이 오브젝트 느낌만 / 이 빛만 / 이 움직임만

형용사("몽환적인")만으로 생성하면 모델은 그 단어의 평균을 그려요. 그래서 무드보드에서 구체적인 어휘를 뽑아요.
다른 앱에서도 쓸 만한 에셋은 공통의 "레퍼런스 라이브러리"에도 올려요.

## 에이전트가 할 일

- [ ] 파일과 메모를 보고 색(hex 4~6개와 역할), 빛, 질감, 움직임으로 정리해 아래에 덧붙이기
- [ ] 메모가 "이 부분만"인 파일은 그 부분만 반영
- [ ] 끝나면 상태를 `review` 로

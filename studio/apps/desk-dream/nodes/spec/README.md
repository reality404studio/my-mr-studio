# 영상 → 명세 번역

새로 만들어야 하는 유일한 단계예요. 영상은 보기 좋지만 Unity가 그대로 따라 할 수 있는 설계도가 아니라서,
영상을 분해해 `studio/scene_spec.yaml` 로 옮겨요.

## 입력

- `reference-video` 단계의 `final.mp4` 와 컷별 파일, 메모
- `moodboard` 단계의 분석 결과

## 절차 (에이전트)

1. 영상을 1초 간격(변화가 빠른 구간은 더 촘촘히)으로 프레임을 뽑아 본다
2. `objects`: 등장하는 오브젝트마다 책상 좌표 위치, 크기, 등장 시점과 방식, 반복 애니메이션
3. `timeline`: 1분 투어의 시간축 이벤트 (초, 가능하면 박)
4. `interactions`: 손 제스처 → 반응 → 효과음. 핸드트래킹만 쓴다
5. `perf`: 오브젝트마다 `ok / costly / impossible` 와 대체안 (72fps 기준)
6. `unknowns`: 영상만으로 정할 수 없는 것 (안 보이는 뒷면, 실제 크기, 손이 닿았을 때 반응 등)
7. 사람이 `unknowns` 에 답해야 하므로, 끝나면 상태를 `review` 로

## 좌표 규칙

원점은 책상 앞 모서리 중앙. x 오른쪽, y 위, z 책상 안쪽, 단위 미터.
MICKE 상판은 x −0.525 ~ +0.525, z 0 ~ 0.50.
